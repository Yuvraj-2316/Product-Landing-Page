# NovaBook Pro — Product Landing Website

A responsive, multi-page product landing website created as part of **Minor Project 02**. NovaBook Pro is a fictional laptop concept designed to demonstrate clean UI design, consistent styling, and basic front-end functionality.

## Overview

The website presents the NovaBook Pro concept through a set of connected pages. It uses a minimal visual style with a cream background, dark green elements, and lime accents.

## Features

- Multi-page website with consistent navigation
- Product overview and feature sections
- Reviews and FAQ page with clearly labelled sample feedback
- Updates signup form with client-side validation and demo confirmation
- Responsive layouts for desktop, tablet, and mobile screens
- Shared CSS styling across pages
- JavaScript-powered interactions

## Pages

| Page | Description |
|---|---|
| Home | Introduces the NovaBook Pro concept |
| Product | Presents the fictional product |
| Features | Highlights product features |
| Reviews & FAQ | Displays sample feedback and common questions |
| Updates | Demonstrates an email signup form |

## Technologies Used

- HTML5 — page structure
- CSS3 — styling and responsive layouts
- JavaScript — form validation and interactive behaviour
- Git and GitHub — version control and project hosting

## Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Navigate between the pages using the website navigation.

## Notes

- NovaBook Pro is a fictional product concept created for educational purposes.
- Review cards contain sample content and are not verified customer testimonials.
- The updates signup form is a front-end demonstration. Email addresses are not stored or sent to a server.
